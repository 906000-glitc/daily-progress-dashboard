# روال | Rava Productivity Workspace

داشبورد فارسی و حرفه‌ای برای برنامه‌ریزی روزانه، تمرکز عمیق و رشد شخصی.

## معماری نسخه فعلی

- `index.html`: ساختار معنایی و محتوای صفحه
- `style.css`: تمام استایل‌ها، تم تاریک و responsive layout
- `app.js`: منطق برنامه، state management، timer و event delegation
- بدون build step و بدون وابستگی runtime؛ مناسب GitHub Pages

## قابلیت‌ها

- مدیریت وظایف با فیلتر همه، در انتظار و تکمیل‌شده
- محاسبه زنده درصد تکمیل وظایف
- تایمر تمرکز ۲۵ دقیقه‌ای با توقف و بازنشانی
- مدیریت اهداف و ثبت پیشرفت پنج‌درصدی
- نمودار عملکرد و بازه‌های تحلیل
- یادداشت سریع با ذخیره خودکار
- تم تاریک با ذخیره انتخاب کاربر
- خروجی نسخه پشتیبان JSON
- میانبر `Ctrl/Cmd + K` برای ساخت وظیفه
- بستن modal با `Escape` یا کلیک بیرون
- طراحی RTL و responsive برای موبایل و دسکتاپ

## نکات رفع باگ

تمام handlerها بعد از آماده‌شدن DOM ثبت می‌شوند، داده‌ها با `try/catch` از localStorage خوانده می‌شوند و فیلترهای وظیفه بر اساس index پایدار state کار می‌کنند.
