# روال | Daily Progress Dashboard

یک داشبورد مینیمال و مدرن فارسی برای برنامه‌ریزی روزانه، عادت‌ها، تمرکز و تحلیل پیشرفت.

## امکانات فعلی

- داشبورد آماری با شاخص‌های تمرکز، زنجیره، تکمیل وظایف و امتیاز بهره‌وری
- برنامه روزانه با وظایف قابل تکمیل
- افزودن وظیفه جدید به‌صورت تعاملی
- نمایش عادت‌های هفتگی
- نمودار انرژی و تمرکز
- بخش بینش عملکرد
- طراحی کاملاً RTL و responsive
- بدون وابستگی به بک‌اند؛ قابل انتشار مستقیم با GitHub Pages

## اجرا

فایل `index.html` را باز کن یا از GitHub Pages استفاده کن. برای نسخه بعدی می‌توان localStorage، ورود کاربران، تقویم، نمودارهای واقعی و اتصال به API اضافه کرد.
