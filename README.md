# روال | Rava Productivity Workspace

داشبورد حرفه‌ای فارسی برای برنامه‌ریزی روزانه، مدیریت هدف، تمرکز عمیق و تحلیل عملکرد؛ منتشرشده با GitHub Pages.

## نسخه فعلی

- داشبورد RTL مدرن و responsive
- وظایف روزانه با وضعیت تکمیل
- نمودار عملکرد هفتگی و شاخص‌های بهره‌وری
- پومودورو و حالت تمرکز
- هدف‌ها و دستاوردها
- یادداشت سریع با ذخیره خودکار در localStorage
- حالت شب
- ساخت وظیفه و هدف با modal
- خروجی داده‌ها و میانبر `Ctrl/Cmd + K`
- میانبر `Escape` برای بستن پنجره‌ها

## انتشار

این پروژه بدون build step و با HTML/CSS/JavaScript خالص اجرا می‌شود و از شاخه `main` روی GitHub Pages سرو می‌شود.

## ایده‌های نسخه بعدی

اتصال به بک‌اند، ورود کاربران، سینک چنددستگاهی، اعلان مرورگر، تقویم واقعی، نمودارهای تعاملی و PWA آفلاین.
