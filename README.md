# روال | Rava Workspace

نسخه حرفه‌ای و responsive داشبورد بهره‌وری با رابط فارسی RTL.

## ماژول‌های فعال

- داشبورد روزانه، وظایف و فیلتر وضعیت
- مدیریت پروژه و فیلتر کردن وظایف بر اساس پروژه
- تقویم هفتگی و یادآورهای قابل مشاهده
- گزارش پیشرفته عملکرد و ثبات
- هدف‌ها، پیشرفت هدف و دستاوردها
- تایمر تمرکز ۲۵ دقیقه‌ای
- یادداشت سریع با ذخیره خودکار
- تغییر تم، خروجی JSON و میانبر `Ctrl/Cmd + K`
- پروفایل قابل ویرایش
- responsive کامل برای موبایل و دسکتاپ

## نکته فنی مهم

GitHub Pages فقط فایل‌های استاتیک را اجرا می‌کند؛ بنابراین ورود کاربر، ذخیره ابری و یادآور مرورگر در این نسخه به‌صورت local-first پیاده‌سازی شده‌اند و داده‌ها در مرورگر ذخیره می‌شوند. برای احراز هویت و همگام‌سازی واقعی بین دستگاه‌ها باید یک backend متصل شود.
